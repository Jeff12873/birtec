Base de données et dictionnaire

Admin Les tables de la base, leurs noms clairs et descriptions (le dictionnaire), l'extraction de tables et la console SQL en lecture seule.

Le dictionnaire

  1. Choisissez une table dans la liste de gauche.
  2. Donnez-lui un nom clair et une description ; faites de même pour ses colonnes. Chaque champ est enregistré quand on le quitte.
  3. Écrivez-y aussi les pièges : « pour une ligne de production, passer par l'arborescence ».

La case devant chaque table dit si elle est donnée à l'IA. « Écarter les tables vides » les décoche d'un coup.

Extraire des tables

Extraire des tables… : cochez les tables, puis Télécharger. Un zip : un CSV par table (séparateur « ; »), la structure et un lisez-moi. 200 000 lignes au plus par table.

Console SQL

Écrivez une requête puis Ctrl + Entrée. Seules les requêtes de lecture sont acceptées, une à la fois, 30 secondes au plus. Copier met le résultat dans le presse-papiers, prêt pour Excel.

Trucs et astuces

  • Après un changement de la base (nouvelle table, nouvelle colonne), Relire la structure.
  • Le dictionnaire profite à tout le monde : un nom clair saisi ici apparaît dans LA PHRASE, les rapports et les réponses de l'IA.
