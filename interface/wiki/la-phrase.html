LA PHRASE : interroger la base

Le bandeau au-dessus de la constellation : on décrit en français ce qu'on veut voir, choix par choix, sans IA et sans SQL.

Voir le cas d'usage : composer une phrase

Pas à pas

  1. Je souhaite consulter les : choisissez la table (les rapports d'intervention, les pièces…).
  2. qui ont : choisissez l'opérateur (ont, n'ont pas, contiennent, commencent par, plus que, entre…), puis la table, le champ et la valeur. Sans valeur, « ont » veut dire que le champ est rempli.
  3. Ajoutez d'autres conditions avec + et qui… ; un autre cas avec + OU un autre cas (une ligne est gardée si elle remplit un des cas).
  4. Choisissez les colonnes avec la pastille + de la première colonne de chaque table ; triez en cliquant les titres (Maj + clic : tri secondaire).
  5. Et maintenant ? : créer un rapport, un indicateur GMAO, enregistrer le SQL ou extraire pour Excel.

Les dates

Après un champ de date : le [jour], avant le, depuis le, entre le … et le …, dans les derniers [3] [mois], il y a plus de [1] [an], ou pendant [ce mois-ci, le mois dernier, cette année…]. Les périodes se recalculent chaque jour : un rapport « des 3 derniers mois » suit le calendrier.

Par où passe la jointure

Quand une condition porte sur une autre table, le menu par … montre par où passe la jointure (par exemple des interventions vers les pièces : par les mouvements de stock, ou par les pièces prévues). Admin le cadenas fixe un passage pour toutes les phrases.

Questions fréquentes

Une valeur que je connais n'est pas proposée

Les valeurs proposées tiennent compte des conditions déjà posées : si elle n'apparaît pas, aucune ligne ne l'a avec ces conditions. Retirez une condition pour vérifier.

Le nombre de lignes est plus grand que prévu

Une jointure peut multiplier les lignes (une intervention et ses trois machines). Le nombre affiché compte les lignes distinctes de la table consultée ; l'aperçu, lui, montre chaque combinaison. Regroupez si besoin.

Une colonne d'une table liée affiche la valeur d'un autre objet

Affichez l'identifiant de chaque table du chemin pour voir d'où vient la ligne, puis envoyez une capture au développeur. Admin vérifiez aussi les types d'objets du modèle de données.

Les utilisateurs voient trop de colonnes dans les choix

La roue à côté du champ choisit les colonnes proposées pour chaque table.

Trucs et astuces

  • Le bouton Excel, à droite du compteur, télécharge toutes les lignes de la phrase dans un classeur, avec les colonnes de l’aperçu (200 000 lignes au plus).
  • Un clic sur une case de l’aperçu la copie dans le presse-papiers : pratique pour un numéro de RI ou un repère.
  • « qui ont [table] », sans champ : garde les lignes qui ont au moins une ligne liée dans cette table (les machines qui ont des pièces, par exemple).
  • La pastille + qui… au bout d'une condition ajoute des conditions sur la table liée : « des pièces qui ont telle famille ».
  • Pour garder une recherche sans en faire un rapport : Et maintenant ? › Enregistrer le SQL.
