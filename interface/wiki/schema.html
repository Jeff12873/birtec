La constellation des tables

Toutes les tables de la base en bulles, reliées par leurs liens. C'est par elle qu'on trouve les tables et le chemin pour aller de l'une à l'autre.

Lire le graphe

  • Principale (rose-rouge) : un objet métier (intervention, demande, machine, pièce, personne).
  • Secondaire (bleu) : le détail rattaché à une principale.
  • Intermédiaire (violet) : une table de liaison entre deux tables.
  • Référentiel (blanc cassé) : une liste de codes (types, familles…).
  • Technique (gris) : journaux, exports, paramètres.

Orange : le chemin choisi. Vert : la table choisie.

Gestes

  • Molette : zoom. Glisser le fond : se déplacer. Glisser une bulle : la déplacer (elle reste là où on la lâche).
  • Ctrl + clic sur une autre bulle : le chemin le plus court entre les deux, avec les clés et le SQL.
  • Ctrl + Maj + clic : construire le chemin soi-même, table par table.
  • Double-clic sur une bulle figée : la libérer. « Tout libérer » : toutes repartent.

Corriger la constellation

  • Le type d'une table : panneau de la table › « Type de table ».
  • Un lien manquant : panneau de la table › « Ajouter un lien ».
  • Un lien nommé est préféré pour les chemins : clic sur le lien pour le nommer.
  • « Tables écartées de l'IA » : celles qui ne sont pas proposées.

Questions fréquentes

Le chemin proposé passe par une table qui n'a rien à voir

Quand un autre chemin est presque aussi court, le panneau le propose (« Autre chemin : par … »). Vous pouvez aussi construire le chemin vous-même avec Ctrl + Maj + clic.

Ma disposition a disparu

Une autre disposition ne fait que montrer : choisissez « Ma disposition » dans le menu des dispositions, elle est gardée dans le fichier de connaissances.

Trucs et astuces

  • Disposez d'abord le graphe à votre goût : le PDF et l'impression reprennent exactement la disposition à l'écran.
  • La disposition « Tables entières » (Impression) tient tout sur une feuille A3 sans chevauchement : idéale à afficher au mur du bureau des méthodes.
