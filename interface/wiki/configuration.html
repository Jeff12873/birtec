Configuration et modèle de données

Admin Ce que LA PHRASE doit savoir de la base pour guider : la table des machines, les fiches techniques, et les types d'objets.

Pas à pas

  1. Configuration › carte Modèle de données › Reconnaître : BiRTEC regarde la forme des tables et quelques valeurs, et propose.
  2. Vérifiez le résumé (machines, fiches techniques).
  3. Dans Types d'objets, vérifiez que chaque type utilisé par vos fiches a sa table ; ajoutez ceux qui manquent (+ Ajouter un type, la table dans la liste).
  4. Enregistrer : le modèle est rangé dans le fichier de connaissances, pour tous les postes.

Questions fréquentes

Quand ajouter un type d'objet à la main ?

Quand des fiches techniques existent sur un nouveau type d'objet (des demandes, des machines…), ou quand des valeurs s'affichent sur la mauvaise ligne. Les types réglés ici passent avant ce que BiRTEC reconnaît tout seul.

La connexion à la GMAO se règle-t-elle ici ?

Non : dans les Réglages du portail, pour toutes les applications. Voir Connexion à la GMAO.
