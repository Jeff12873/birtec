Questions fréquentes et dépannage

« Connexion à la GMAO indisponible »

Vérifiez l'étiquette GMAO en haut. Voir Connexion à la GMAO.

« La table … n'est pas dans le chemin »

Une condition ou une colonne porte sur une table qui n'est pas reliée : ajoutez-la avec Ctrl + Maj + clic dans la constellation.

Une valeur affichée appartient à une autre ligne

Voir Fiches techniques. Mettez BiRTEC à jour, puis Mettre à jour le rapport.

Vérifiez les types d'objets du modèle de données.

Le rapport ne s'ouvre pas dans la GMAO

Vérifiez la charte des rapports (source de données, profil de connexion) dans Connaissances, puis refaites le .rptdesign.

« Java n'est pas installé »

L'installation de K.NOVA n'est pas allée au bout : relancez-la.

Excel n'actualise pas les requêtes

Voir Extraire pour Excel : disque local, dossier entier.
