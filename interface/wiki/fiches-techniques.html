Fiches techniques et parcs dans la phrase

Les choix guidés de LA PHRASE : chercher par parc ou machine de l'arborescence, et par réponse d'une fiche technique (modèle, champ, valeur).

Par parc ou par machine

  1. La table des machines doit être dans le chemin (Ctrl + Maj + clic pour l'ajouter).
  2. Condition › dans le parc (les parcs d'AITEC) ou sous la machine : toutes les machines de l'arborescence en dessous sont comprises.
  3. « et tout ce qui est dessous » sur une condition de la table des machines garde aussi toute la descendance.

Par fiche technique

  1. Consultez la table de l'objet (pièces, rapports d'intervention…).
  2. Condition › fiche technique › le modèle › le champ › la valeur. Seuls les modèles et champs utilisés pour ce type d'objet sont proposés.
  3. Pour afficher les réponses en colonnes, ajoutez au chemin les tables des fiches : chaque ligne ne montre que les réponses de son propre objet.

Questions fréquentes

« Fiches techniques non décrites » ou « Machines non décrites »

Le modèle de données du site n'est pas réglé : Configuration › Modèle de données › Reconnaître, vérifier, Enregistrer. Voir Configuration.

Une ligne affiche la réponse d'un autre objet (un 1 au lieu d'un 0)

Mettez BiRTEC à jour (corrigé en 0.15.12), puis rouvrez la phrase et cliquez Mettre à jour sur le rapport : un rapport déjà fabriqué garde son ancienne requête.

Si le type de l'objet n'est pas reconnu, ajoutez-le dans Configuration › Modèle de données › Types d'objets (par exemple RI → la table des rapports).

« La table des machines n'est pas dans le chemin »

Ajoutez-la avec Ctrl + Maj + clic sur sa bulle, puis refaites la condition.

Trucs et astuces

  • Pour vérifier une valeur de fiche, affichez à côté l'identifiant de l'objet et celui de la table des réponses : ils doivent être identiques sur chaque ligne.
