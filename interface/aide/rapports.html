Rapports : créer, voir, exporter

Les vignettes

Chaque rapport est une vignette : son titre, deux lignes de description (écrites une fois par l'IA, corrigeables par l'administrateur avec le crayon), son contenu et sa date. Un clic ouvre le rapport à droite : paramètres, aperçu, export.

La petite constellation d'une vignette montre les tables du rapport (enregistrées s'il vient de la constellation, sinon lues dans son SQL). En mode administrateur, un clic dessus propose de le rouvrir dans la constellation : son chemin et ses filtres s'allument, et « Et maintenant ? › Mettre à jour » rouvre son formulaire avec le chemin du jour.

Créer un rapport (administrateur)

On part de la constellation : faites la phrase (et, si besoin, un regroupement), puis Et maintenant ? › Créer un rapport, donnez un titre : le rapport est un tableau des colonnes de l'aperçu (ou des groupes et de leurs calculs), dans le même tri. Pour le changer : rouvrez-le dans la constellation, retouchez la phrase, puis « Mettre à jour ». Le bouton Télécharger le .rptdesign donne le fichier, à ouvrir dans BIRT ou à déposer dans la GMAO.

BiRTEC vérifie le fichier dans le moteur BIRT puis le fait tourner avec les valeurs par défaut des paramètres. En cas d'erreur (colonne inconnue, faute dans la requête…), l'IA corrige la description, deux fois au plus.

Description d'un rapport

{
  "titre": "Heures par équipement",
  "sousTitre": "Période choisie",
  "orientation": "portrait",
  "requete": "SELECT … AS famille, … AS equipement, … AS heures FROM … WHERE date >= ? AND date < ? ORDER BY famille",
  "parametres": [ { "nom": "debut", "libelle": "Du", "type": "texte", "defaut": "20260101" },
                  { "nom": "fin", "libelle": "Au", "type": "texte", "defaut": "20270101" } ],
  "liaisons": ["debut", "fin"],
  "colonnes": [ { "champ": "equipement", "libelle": "Équipement" },
                { "champ": "heures", "libelle": "Heures", "format": "decimal", "total": "somme" } ],
  "groupes": [ { "champ": "famille", "libelle": "Famille", "sousTotaux": true } ]
}
  • liaisons : le paramètre de chaque « ? » de la requête, dans l'ordre.
  • format : texte, entier, decimal, pourcentage, date, dateheure.
  • total : somme, moyenne, nombre, min, max (total général et sous-totaux de groupe).

Aperçu et export

Choisissez les paramètres, puis Aperçu. Exporter produit le fichier au format choisi : PDF, Excel, Word, page web, LibreOffice (Writer, Calc) ou PowerPoint. Pour l'aperçu, BiRTEC utilise sa propre connexion MySQL, quelle que soit celle écrite dans le rapport.

Thème, image, logo, description

Dans le détail d'un rapport créé par BiRTEC, « Aspect » : un thème (charte du site, sobre, bleu, vert, orange, noir et blanc), une image centrée en haut (importée dans le fichier .ktec), le logo de la GMAO en haut de page. « Appliquer » refait le rapport sans passer par l'IA. La description du rapport (en en-tête ou en bas de page) se demande à l'assistant.

BiRTEC compte les lignes du rapport : un rapport vide avec les valeurs par défaut est signalé (filtre trop strict, mauvaise table…).

Aspect et mise dans la GMAO

Couleurs, police, feuille de style, logo, nom de la source de données, profil de connexion et paramètres cachés passés par la GMAO viennent de la charte des rapports (écran Connaissances, bouton « Charte des rapports ») : réglée comme vos rapports existants, elle donne des rapports qui leur ressemblent et se déposent tels quels. Le fichier est au format de BIRT Report Designer 4.8. Le mot de passe n'est jamais écrit dedans.

Le bouton .rptdesign donne le fichier, à déposer là où la GMAO range ses rapports.

Rapports existants

Dans Connaissances → Fichiers BIRT, le bouton œil d'un rapport modèle le copie dans les rapports pour l'aperçu. Si le rapport utilise une feuille de style ou une bibliothèque (ex. _style.css), ajoutez-la dans les ressources : sinon BiRTEC affiche un avertissement, et le rapport sort sans ces styles.
