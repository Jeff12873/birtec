Installation et version hors ligne

BiRTEC est une application de la suite KTEC : elle s'installe avec KTEC, dans le profil de l'utilisateur, sans droits d'administrateur. KTEC installe une seule fois ce que les applications partagent : le moteur d'IA et son modèle, Java, le moteur BIRT et le pilote MySQL.

BiRTEC s'ouvre depuis le portail KTEC (sa tuile), et l'on passe d'une application à l'autre par le bas du menu. La connexion MySQL est commune : le mot de passe n'est demandé qu'une fois.

Fichier de connaissances

Les connaissances du site sont dans le fichier .ktec, commun à toutes les applications. Au premier lancement de KTEC, l'ancien fichier connaissances.birtec et les rapports de BiRTEC sont copiés dans Documents/KTEC ; l'original reste en place.

Poste sans Internet

Un kit hors ligne de KTEC contient tout, et se copie sur une clé USB.
