Installation et version hors ligne

BiRTEC s'installe dans le profil de l'utilisateur, sans droits d'administrateur : Preparer BiRTEC.bat (Windows) ou sh preparer-birtec.sh (Linux). La préparation installe le moteur d'IA, le modèle, Java, le moteur BIRT et le pilote MySQL, puis crée les raccourcis.

Si IASSITEC est déjà installé sur le poste, ses modèles d'IA sont réutilisés.

Poste sans Internet

Un kit hors ligne contient tout : il se fabrique sur un PC connecté avec Fabriquer kit hors ligne.bat ou sh fabriquer-kit-hors-ligne.sh, puis se copie sur une clé USB.
