Configuration

Connexion MySQL

La connexion à la GMAO se règle dans les Réglages du lanceur KTEC, par l'administrateur : serveur, port, base, compte de lecture (et compte d'écriture pour AITEC). Elle est rangée chiffrée dans le fichier de connaissances ; les applications s'y connectent toutes seules, sans mot de passe à taper.

Si le compte peut modifier la base, BiRTEC le signale : il n'écrit jamais, mais un compte en lecture seule est la vraie protection.

Fichiers BIRT et connaissances

Les rapports modèles, bibliothèques et feuilles de style se rangent dans l'écran Connaissances, avec tout ce que BiRTEC sait de votre GMAO.

Dossier de travail

Les rapports créés par BiRTEC y sont rangés (rapports/), ainsi que, par défaut, le fichier connaissances.ktec. Par défaut : Documents/BiRTEC.
