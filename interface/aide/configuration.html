Configuration et fichiers BIRT

Connexion MySQL

Serveur, port, base et utilisateur sont enregistrés sur ce poste. Le mot de passe est demandé à chaque ouverture, gardé en mémoire seulement, et transmis au moteur Java sans jamais être écrit sur le disque.

Si le compte peut modifier la base, BiRTEC le signale : il n'écrit jamais, mais un compte en lecture seule est la vraie protection.

Fichiers BIRT

  • Rapports modèles (.rptdesign, .rpttemplate) : la mise en page à reprendre (page maîtresse, styles, logo, en-tête).
  • Bibliothèques et ressources (.rptlibrary, .properties, images, CSS…) : utilisées par vos rapports.

Ils sont rangés dans le dossier de travail (par défaut Documents/BiRTEC).
