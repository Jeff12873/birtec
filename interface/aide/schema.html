Constellation des tables

Le premier écran de BiRTEC : toutes les tables en bulles, reliées par leurs liens, qui se placent toutes seules (les bulles se repoussent, les liens les rapprochent). À l'arrivée, la vue dézoome pendant que les étoiles s'allument et que les liens se tracent (en raccourci aux visites suivantes).

Plus une bulle est grosse, plus la table a de liens. Sa couleur dit son type :

  • Principale (jaune) : un objet métier, ce qu'on veut voir — RI, DI, FI, machine, pièce, personne.
  • Secondaire (bleu) : le détail rattaché à une principale.
  • Intermédiaire (violet) : une table de liaison entre deux tables ; son nom les réunit souvent (ARTMAC = ARTicle + MAChine).
  • Référentiel (turquoise) : une liste de codes (types, familles…).
  • Technique (gris) : journaux, exports, paramètres.

BiRTEC devine le type ; l'administrateur le corrige dans le panneau d'une table (« Type de table »). Orange : le chemin choisi.

  • Molette : zoomer et dézoomer. Glisser le fond : se déplacer. Glisser une bulle : la déplacer. Tout voir : recadrer.
  • Organiser à la main : avec « Figer en lâchant » (coché par défaut), une bulle déplacée reste là où on la lâche (un point sombre la marque) ; les autres s'arrangent autour. Double-clic sur une bulle figée : la libérer. « Tout libérer » : toutes repartent.
  • Curseurs sous le graphe : Force des liens (les tables liées se rapprochent) et Écartement (les bulles se repoussent). Clés de liaison : la clé de chaque lien écrite le long de sa ligne (ex. « ID_DI », ou « ID_PERE = ID_ARTICLE » quand les colonnes diffèrent) ; zoomez si une ligne est trop courte pour l'afficher. Reprises à l'impression.
  • Survol d'une bulle : ses tables liées s'éclairent. Les noms apparaissent en zoomant.
  • Clic sur une bulle : c'est la source ; son nom clair, sa description, sa prise en compte par l'IA, ses tables liées.
  • Ctrl + Maj + clic : construire le chemin soi-même, table par table (la première table cliquée est le départ). Si une table n'est pas directement liée à la précédente, le plus court passage entre les deux est ajouté. « Retirer la dernière » revient en arrière.
  • Ctrl + clic sur une autre bulle : le chemin le plus court entre les deux, tracé en orange, avec les tables traversées, les clés de chaque jointure et le SQL à copier. Les tables voisines du chemin restent nettes et nommées : ce sont celles qu'on peut y ajouter.
  • Le chemin préféré : un lien nommé, puis une table de liaison qui réunit justement les deux tables (ARTMAC, faite pour relier ARTICLE et MACHINE, plutôt qu'une autre table qui touche aussi les deux), puis une table « fille ». Quand un autre chemin est presque aussi court, le panneau le propose : « Autre chemin : par … ».
  • Le SQL part toujours de la première table (SELECT * FROM …) et ajoute les jointures dans un ordre que BIRT accepte : chaque jointure ne cite que des tables déjà jointes.
  • Clic sur un lien : le nommer et le décrire. Un lien nommé est préféré pour les chemins (ceux du schéma comme ceux donnés à l'IA).
  • Ajouter un lien manquant (dans le panneau d'une table) : quand une colonne pointe vers une autre table sans suivre la convention ID_XXX.
  • Le cadre Raccourcis, en haut à droite du graphe, les rappelle ; un clic sur son titre le replie.
  • Chercher une table : le graphe se centre dessus. « Tables écartées de l'IA » les montre en grisé.

Télécharger les données

Dans le panneau de droite : Télécharger la table (la table choisie) ou, après un Ctrl + clic, Télécharger les N tables du chemin en surbrillance (une table vue deux fois n'est téléchargée qu'une fois). Le fichier .zip contient un CSV par table (s'ouvre dans Excel), la structure avec les noms clairs, et un lisez-moi.

La constellation en PDF

Constellation en PDF (en haut) enregistre directement un fichier PDF dans le dossier des téléchargements : une page A3 paysage sur fond blanc avec tout le graphe tel qu'il est disposé, le nom de chaque table, le chemin choisi en surbrillance avec ses clés, et une légende. Imprimer envoie la même page à l'imprimante. Disposez d'abord le graphe à votre goût : le PDF reprend la disposition à l'écran.

Tout ce qui est saisi est gardé dans le fichier .ktec, y compris la disposition des bulles : elle est retrouvée à chaque ouverture et reprise par l'impression.
