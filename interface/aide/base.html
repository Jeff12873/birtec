Base de données et dictionnaire

La liste de gauche montre les tables. La case devant chaque table dit si elle est donnée à l'IA : décochez les tables inutiles (techniques, vides, hors sujet). « Écarter les tables vides » le fait d'un coup quand la connexion est ouverte. Le choix est gardé dans le fichier .ktec.

Dictionnaire

Pour la table choisie : un nom clair et une description pour la table et pour chaque colonne. Ils sont donnés à l'IA, qui ne devine plus le sens des abréviations (« ot » = ordre de travail). Écrivez-y aussi les pièges : « pour une ligne de production, passer par la table de l’arborescence ». Chaque champ est enregistré quand on le quitte.

Les liens entre tables se nomment dans l'écran Constellation.

Extraire des données

Extraire des tables… : cochez les tables (filtre, tout cocher) puis Télécharger ; ou, dans le détail d'une table, Télécharger cette table. Vous obtenez un fichier .zip : un CSV par table (séparateur « ; », s'ouvre dans Excel), _structure.csv (colonnes, noms clairs, descriptions) et un lisez-moi. 200 000 lignes au plus par table ; il faut la connexion MySQL.

Console SQL

Écrivez une requête puis Ctrl+Entrée. Seules les requêtes de lecture sont acceptées (SELECT, WITH, SHOW, DESCRIBE, EXPLAIN), une à la fois, 30 secondes au plus. Copier met le résultat dans le presse-papiers, prêt à coller dans Excel.

Connexion fermée : la structure gardée dans le fichier .ktec reste consultable. Si la base change, Relire la structure.
