Base de données et console SQL

La liste de gauche montre toutes les tables et vues. Un clic affiche les colonnes, les clés, les liens vers les autres tables, et permet de voir les 20 premières lignes.

Console SQL

Écrivez une requête puis Ctrl+Entrée. Seules les requêtes de lecture sont acceptées (SELECT, WITH, SHOW, DESCRIBE, EXPLAIN), une à la fois, 200 lignes au plus, 30 secondes au plus. Copier met le résultat dans le presse-papiers, prêt à coller dans Excel.

Si la base change (nouvelle table), cliquez sur Relire la structure.
