Premiers pas

BiRTEC aide à écrire les requêtes SQL et à créer les rapports BIRT de la GMAO, avec une IA qui tourne sur ce poste et qui connaît la structure de votre base MySQL et les habitudes de votre site.

1. Connexion à la base

Dans Configuration, renseignez le serveur, le port, la base et l'utilisateur MySQL (de préférence un compte en lecture seule). Le mot de passe est demandé à chaque ouverture de BiRTEC et n'est jamais enregistré.

2. Connaissances du site

Dans Connaissances, « Importer un dossier » range dans le fichier .birtec vos documents : export de structure de la base, requêtes .sql, notes, rapports modèles, bibliothèques… Écrivez aussi une note « toujours » avec les conventions de votre GMAO (format des dates, statuts…) : l'IA la lit à chaque question.

3. Questions et rapports

Dans l'Assistant, décrivez ce que vous voulez : « nombre d'interventions par équipement sur une période, avec le total ». L'IA écrit la requête (Exécuter montre le résultat) puis la description du rapport : Créer le rapport fabrique le fichier .rptdesign, le vérifie dans le moteur BIRT et l'ouvre dans Rapports pour l'aperçu et l'export.
