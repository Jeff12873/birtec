Premiers pas

BiRTEC crée les rapports BIRT et les indicateurs ITM de la GMAO, à partir de la vraie structure de votre base MySQL et de ce qu'il sait de votre site (fichier .ktec).

1. Connexion à la base

Dans Configuration, renseignez le serveur, le port, la base et l'utilisateur MySQL (de préférence un compte en lecture seule). Le mot de passe est demandé à chaque ouverture et n'est jamais enregistré.

2. Connaissances du site

Le fichier .ktec contient le dictionnaire de la base (noms clairs, descriptions, liens), les conventions, les rapports modèles et les indicateurs. Copiez-le d'un poste à l'autre. Complétez le dictionnaire dans Base de données et Constellation : plus il est riche, plus les champs proposés sont clairs.

3. Créer un rapport ou un indicateur

Nouveau : choisissez un rapport ou un indicateur ITM. Un rapport se compose de blocs (tableaux, graphiques, tableaux croisés, chiffres clés, textes), décrits en une phrase (« Remplir avec l'IA ») ou construits avec les champs, ou en SQL libre. L'aperçu suit chaque choix. Après l'enregistrement, BiRTEC propose de faire aussi l'autre (indicateur ↔ rapport).

4. Retrouver, exporter, copier

Rapports : aperçu, export (PDF, Excel, Word…), fichier .rptdesign pour la GMAO. Indicateurs ITM : les deux requêtes à copier dans la GMAO. Accueil : vos indicateurs du jour et vos raccourcis, à organiser.

5. Une question ?

Sur l'Accueil, « Une question ? » : l'IA explique la base ou écrit une requête inhabituelle (calcul, sous-requête), contrôlée par BiRTEC.

Le menu

  • Créer : Nouveau (rapport ou indicateur ITM).
  • Mes créations : Rapports, Indicateurs ITM.
  • Ma base : Base de données (tables, dictionnaire, console SQL), Constellation des tables, Connaissances (fichier .ktec).
  • Réglages : Configuration (connexion MySQL, poste).
