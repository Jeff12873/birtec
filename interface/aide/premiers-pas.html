Premiers pas

BiRTEC crée les rapports BIRT et les indicateurs GMAO de la GMAO, à partir de la vraie structure de votre base MySQL et de ce qu'il sait de votre site (fichier .ktec).

1. Connexion à la base

La connexion à la base de la GMAO est réglée une fois par l'administrateur (Réglages du lanceur KTEC), avec un compte en lecture seule : BiRTEC s'y connecte tout seul.

2. Connaissances du site

Le fichier .ktec contient le dictionnaire de la base (noms clairs, descriptions, liens), les conventions, les rapports modèles et les indicateurs. Copiez-le d'un poste à l'autre. Complétez le dictionnaire dans Base de données et Constellation : plus il est riche, plus les champs proposés sont clairs.

3. Créer un rapport ou un indicateur

Nouveau : choisissez un rapport ou un indicateur GMAO. Un rapport se compose de blocs (tableaux, graphiques, tableaux croisés, chiffres clés, textes), décrits en une phrase (« Remplir avec l'IA ») ou construits avec les champs, ou en SQL libre. L'aperçu suit chaque choix. Après l'enregistrement, BiRTEC propose de faire aussi l'autre (indicateur ↔ rapport).

4. Retrouver, exporter, copier

Rapports : aperçu, export (PDF, Excel, Word…), fichier .rptdesign pour la GMAO. Indicateurs GMAO : les deux requêtes à copier dans la GMAO.

BiRTEC s'ouvre sur la Constellation des tables : c'est par elle qu'on trouve les tables et leurs chemins de jointure.

5. Une question ?

La question libre (depuis l'aide) : l'IA explique la base ou écrit une requête inhabituelle (calcul, sous-requête), contrôlée par BiRTEC.

Le menu

  • Créer : Nouveau (rapport ou indicateur GMAO).
  • Mes créations : Rapports, Indicateurs GMAO.
  • Ma base : Base de données (tables, dictionnaire, console SQL), Constellation des tables, Connaissances (fichier .ktec).
  • Réglages : Configuration (connexion MySQL, poste).
